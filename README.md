# BASEIO — Local AI Hub

Run AI models on your own Windows PC as easily as installing a game.

BASEIO detects your hardware, shows which AI models will run well on it,
downloads them through [Ollama](https://ollama.com), and lets you chat with
them locally. Nothing you type leaves your computer.

## Status
Early MVP (v0.1.0). See [AI_HANDOFF.md](AI_HANDOFF.md) for exact status and
[ROADMAP.md](ROADMAP.md) for what's next.

## Quick start (developers)
```powershell
npm install
npm run tauri dev
```
